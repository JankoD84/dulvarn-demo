# Demo Scenario Stability

This repository is a demo/sandbox, but changes can still matter.

Changes may affect:

1. The demo itself.
2. Dulvarn integration demonstrations.
3. Expected showcase decision scenarios described outside this repository.
4. Screenshots, docs, and customer demos.
5. CI signals used by Dulvarn demonstrations.

## Rule

Preserve deterministic scenario behavior unless the task explicitly asks to change it.

A change that intentionally alters routes, auth behavior, mock release records, validation outcomes, or test expectations must include a demo-impact note in the final report or review.
