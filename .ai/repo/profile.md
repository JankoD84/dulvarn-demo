# Repository Profile

## Repository

`dulvarn-demo`

## Purpose

> This repository is used as a live demo environment for [Dulvarn](https://dulvarn.com) — a Release Control System that gives every pull request an explicit GO, CONDITIONAL GO, or NO-GO decision.

## Technology stack

Python, FastAPI, pytest

## Runtime and main areas

- `.agents/`
- `app/`
- `tests/`
- `.ai/`
- `.zed/`
- `.github/`

This repository is part of the Dulvarn active repository ecosystem under `platform/`.
Use repository-local code, tests, schemas and canonical documentation as the source of truth.
