# Repository Profile

## Repository

`dulvarn-demo`

## Purpose

This repository is used as a live demo environment for [Dulvarn](https://dulvarn.com) — an independent Release Decision Intelligence System (RDIS). This demo may show release-related validation signals, but it is not canonical governed `GO` / `CONDITIONAL_GO` / `NO_GO` release authority.

## Technology stack

Python, FastAPI, pytest

## Runtime and main areas

- `.agents/`
- `app/`
- `tests/`
- `.ai/`
- `.zed/`
- `.github/`

## Dulvarn ecosystem role

This repository is part of the Dulvarn active repository ecosystem under `platform/`.
Use repository-local code, tests, schemas and canonical documentation as the source of truth.
